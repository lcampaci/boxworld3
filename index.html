Ajuda

Coloque todas as caixas sobre os alvos amarelos.

Use as setas ou W/A/S/D para mover.

Atalhos do teclado:

  • Ctrl + R: reiniciar a fase
  • Ctrl + Z: desfazer somente o último movimento
  • Ctrl + B: fase anterior
  • Ctrl + M: próxima fase (quando estiver liberada)
  • Ctrl + A: abrir esta tela de ajuda

As fases são desbloqueadas em sequência: conclua uma fase para liberar a próxima.
